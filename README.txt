Thinbus SRP: Secure Remote Password (SRP-6a) protocol implementation for Browsers 
talking to Java servers. 

Copyright (c) Simon Massey, 2014


README

This package provides a  Secure Remote Password (SRP-6a) client sessionn implementation 
for Javascript / EMCAScript in a browser talking to Java on the server to perform a zero 
knowledge proof of password.

Comming soon is a Java port of Ruslan Zazvacky's PHP demo page using this library

https://github.com/RuslanZavacky/srp-6a-demo

N.B. Code currently depends on the soon to be released 1.5.0 version of Nimbus SRP6a so 
you have have to git clone then mvn install that locally if you are keen to use this 
code today.
